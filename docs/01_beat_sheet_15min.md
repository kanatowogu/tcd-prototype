# 《更正部 / The Correction Department (TCD)》15 分钟四阶段因果锁链与微引导节拍表（v2.1 · 80年代异世界拟真版）

> **世界观与美术口径锁定**：
> - **时代与舞台质地**：1980 年代冷峻模拟科技（打孔考勤卡、复写纸、热敏传真卷、拨号内线、投币热汤机、机械升降井、暖炭黑桌面 + 微茶色档案纸 + 黑白/炭灰老式 CRT 监视器），架空市政异世界背景（非现代中国、非写实美国，无手机/二维码/外卖/网贷等现代元素）。
> - **后期灯光与崩溃口径**：阶段三触发 `lensBroken` 后，头顶白灯熄灭，无声、慢速旋转的**品红 / 冷青 / 琥珀**三色迪斯科光斑扫过桌面；UI 出现克制的官僚系统级误编目与漆皮剥落，不使用廉价跳脸或血浆糊屏。
> - **双结局唯我论闭环**：Branch A（心理学解离防御 · 亲手涂黑重建日常）与 Branch B（超自然逆模因同化 · 表皮剥落归并）互为 50/50 镜像。

## 二、 5 分钟课堂 Pitch 快进演示开发备注（仅开发参考，不进正文字幕）
